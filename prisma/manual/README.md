# Manual Supabase setup

These SQL files are the bootstrap script for the Supabase Postgres
database. Run them once, in order, in **Supabase → SQL Editor → New
query**.

| Step | File | What it does |
| ---- | ---- | ------------ |
| 1 | `01-init-schema.sql` | Creates every table, enum, foreign key, and index — generated by `prisma migrate diff --from-empty`. |
| 2 | `02-rls-policies.sql` | Enables Row-Level Security on every workspace-scoped table; adds policies tying visibility to `Membership`. |
| 3 | (later) `03-seed-york.sql` | Optional — creates the first `Workspace` ("York Planning") + the owner `Membership` for `jerome@apphero.tech`. |

## How to apply

1. Open <https://app.supabase.com/project/fjspuzpdbjxekvizhpfq/sql/new>
2. Paste the contents of `01-init-schema.sql`, click **Run**. Wait for "Success".
3. Paste `02-rls-policies.sql`, click **Run**.
4. (Optional) Paste `03-seed-york.sql`.

After step 2, the schema is identical to what `prisma db push` would have
produced, plus tenant isolation. Prisma Client introspection will pick it
up on the next `prisma generate`.
